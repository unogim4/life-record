# 인생기록부

선택지로 한 사람의 일생을 걸어가고, 게임이 끝나면 그 판이 한 편의 소설로 쓰여지는 페이퍼형 로그라이크.

- 태아기부터 노년기까지 8단계, 단계마다 소설·드라마 클리셰에서 가져온 사건과 선택지
- 행복(LP)·지성·건강·정신력·재력이 선택마다 복합적으로 변하고, 건강이나 행복이 바닥나면 생이 끝난다
- 앞에서 깐 복선(소꿉친구, 출생의 비밀, 어머니의 꿈…)이 뒤의 선택지로 돌아온다
- 엔딩에서 Claude가 그 판의 기록으로 생애 소설을 쓴다 (API 키가 없으면 기록을 엮은 임시 소설)

## 실행

**Windows**: `인생기록부 실행.bat`을 더블클릭하면 설치·빌드 후 브라우저가 열립니다. (Node.js 22 이상 필요)

직접 실행:

```bash
npm install
npm run dev      # 개발 서버 http://localhost:5173
```

AI 소설을 쓰려면 `.env.example`을 `.env`로 복사하고 `ANTHROPIC_API_KEY`를 넣습니다.

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버 (소설 API 포함) |
| `npm run check` | 타입 검사 + 이벤트 데이터 검사 |
| `npm run sim -- 5000` | 무작위 플레이 밸런스 시뮬레이션 |
| `npm run build` / `npm start` | 배포용 빌드 / 서버 (기본 포트 8080) |

## 구조

```
src/            게임 화면·엔진·엔딩·소설 요청 (Vite + TypeScript)
src/data/       생애 단계, flag, 단계별 이벤트
server/         소설 API (프롬프트 조립 + Claude 스트리밍), 배포용 서버
tools/          데이터 검사, 밸런스 시뮬레이터
```

개발 계획과 진행 상황은 [PLAN.md](PLAN.md)에 있습니다.
